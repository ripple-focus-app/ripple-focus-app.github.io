You set an app limit, then tap "Ignore Limit" every time

I am the developer of Ripple, a free app blocker, so keep that in mind. This page is for people whose app limits run out and get skipped within a second, and for parents whose child has learned the same trick.

Why the built in limit gets skipped

On iPhone, when a Screen Time limit runs out without a passcode, the screen offers Ignore Limit, and from there one more minute, 15 more minutes or the rest of the day. On Android, a Digital Wellbeing app timer greys out the app, and you can open Digital Wellbeing and remove or change the timer. Both are fine as a reminder. They are weak when the person holding the phone is the person who wants more time.

On iPhone you can ask someone else to set the Screen Time passcode, so the extra time needs that person. For many adults this is enough, and it costs nothing.

On Android, for yourself

Ripple for Android (v0.1.22, Android 8.0 or later) lets you give each app a daily amount, block apps during set hours, cap how many times a day an app can be opened, and lock into focus with one tap. When the amount runs out the app is blocked for the rest of the day. Making a rule stricter works right away. Loosening one means a wait of 15 minutes by default, which you can change to 30 minutes, 1 hour or 2 hours, or entering an unlock code. The wait gives the urge time to pass. If you would sit out any wait, give the code to someone you trust and turn on strict mode so that only the code works.

On Android, for a child

Set the rules on the child's phone and keep the unlock code to yourself. In strict mode only the code loosens a rule, at most 3 successful uses a day, and on Android 11 or later Anti-Uninstall turns on as well. Changing the clock does not shorten a wait. If you lose the code, you can request a reset and it is lifted after 72 hours. Ripple has no remote control, so you set everything on the child's phone in person.

Ripple needs the accessibility permission on Android. If that permission is switched off, blocking stops, so check it now and then, especially after a system update.

On iPhone

Ripple for iPhone is v0.1.5 (iOS 16 or later). It blocks chosen apps during set hours, stops apps from being deleted, guards against clock changes and uses an unlock code. It has no daily amounts, no strict mode and no open count limit. If you want a daily amount on iPhone, use Screen Time and let someone else keep the passcode. Ripple's schedules can cover the hours where you know you slip, such as late evening.
