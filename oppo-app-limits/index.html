App limits on an OPPO, OnePlus or realme phone that you keep removing

I am the developer of Ripple, a free app blocker, so keep that in mind. My own test phone is an OPPO, which is why I wrote this page. It is for people on ColorOS or realme UI who want to limit their own use, and for parents who give one of these phones to a child.

What the phone already gives you

These phones have screen time settings where you can see how long each app was used and set an app timer. Global models also have Digital Wellbeing and Google Family Link. If the built in timer works for you, keep it.

The trouble most people describe is that the timer is easy to undo. When time runs out you can extend it or switch it off in Settings. A child who knows the phone well can often do the same.

If the phone is yours

Ripple for Android (v0.1.22, Android 8.0 or later) gives each app a daily amount, blocks apps during set hours, caps how many times a day an app can be opened, and has a one tap focus lock. A stricter rule applies at once. Loosening a rule means waiting 15 minutes by default, and you can change the wait to 30 minutes, 1 hour or 2 hours. An unlock code loosens rules too. If you know you would sit out any wait, hand the code to someone you trust and turn on strict mode so only the code works. Setting a daily amount of 0 minutes keeps an app closed all day.

If the phone is your child's

Set the rules on the child's phone and keep the unlock code yourself. With strict mode on, only the code loosens a rule, with at most 3 successful uses a day, and Anti-Uninstall turns on with it on Android 11 or later. Moving the clock forward does not end a wait early. If you lose the code, a request lifts it after 72 hours.

Ripple has no remote control. Everything is set on the child's phone in person. If you need to change limits from your own phone, Family Link can do that and Ripple cannot.

Settings to check on ColorOS and realme UI

These systems close background apps fairly often. In Ripple's app settings, allow it to start on its own and to run in the background, and turn off battery optimisation for it. Menu names differ between versions. Ripple also needs the accessibility permission, and blocking stops if that permission is switched off, so look at it now and then.

One known gap: if a blocked app is open in a floating window (the small window mode), Ripple can only cover it. You have to close the small window yourself. A child could learn this, so it is worth knowing about.

Ripple is not on Google Play or the OPPO app store. It is installed from the APK on its website.

On iPhone

Ripple for iPhone is v0.1.5 (iOS 16 or later). It blocks chosen apps during set hours, stops apps being deleted, protects against clock changes and uses an unlock code. It has no daily amounts, no 0 minute limit, no strict mode and no open count limit. For daily amounts, Apple's Screen Time with a passcode only you know does that.
