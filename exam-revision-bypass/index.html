Exam revision when the phone keeps winning

I am the developer of Ripple, a free app blocker, so keep that in mind. This page is for two kinds of people in exam season. One is an adult revising for finals, a driving theory test or a work qualification who sets a limit and then removes it ten minutes later. The other is a parent whose teenager is revising for GCSEs or similar and gets around every limit they set.

Why limits stop working

Most limits fail in the same few ways. The person who set the limit also knows how to undo it. The extra 15 minutes button is one tap away. Teenagers find the rest: changing the phone's date and time, deleting and reinstalling an app, or uninstalling the blocker itself. A limit that holds needs each of those exits to be slow or closed.

If you are the one revising (Android)

Ripple for Android (v0.1.21, Android 8.0 or later) lets you give each app a daily amount, block apps during set hours, cap how many times a day an app can be opened, or start a one-tap focus lock when you sit down to revise. Making a rule stricter applies right away. Loosening any rule takes a 15 minute wait (30 minutes for short video apps), or an unlock code. If you know you will wait out the 15 minutes, give the unlock code to a friend or family member and turn on strict mode, so only the code loosens a rule.

A daily amount of 0 minutes keeps an app closed all day, which suits the weeks right before an exam. You still keep calls, messages and the apps you need for revision.

If your teenager is revising (Android)

Set the rules on the teenager's phone and keep the unlock code yourself. With strict mode on, only the code loosens a rule, at most 3 successful uses a day, and Anti-Uninstall turns on with it on Android 11 or later. Changing the phone clock does not end a wait early. If you forget the code, a request lifts it after 72 hours.

Some honest limits. Ripple has no remote control, so you set everything on the teenager's phone in person. It needs the accessibility permission to stay on, and if that permission gets switched off in Settings, blocking stops, so check it now and then. On some phones a blocked app can show for a moment before Ripple closes it. Ripple is not on Google Play and is installed from the APK on its website.

On iPhone

Ripple for iPhone is v0.1.5 (iOS 16 or later). It blocks chosen apps during set hours, stops apps being deleted, protects against clock changes and uses an unlock code. It has no daily amounts, no 0 minute limit, no strict mode and no open count limit. For revision you could block games and social apps from 16:00 to 21:00 on school days. Apple's Screen Time with a passcode the teenager does not know covers daily amounts.
