App limits on a Huawei or Honor phone

I am the developer of Ripple, a free app blocker, so keep that in mind. This page is for people with a Huawei or Honor phone who want to cut their own scrolling, and for parents whose child has one of these phones.

Check which system the phone runs

Ripple is an Android app installed from an APK. It runs on Honor phones with MagicOS and on Huawei phones with EMUI or HarmonyOS 4 and earlier. Huawei phones that moved to HarmonyOS NEXT (sold as HarmonyOS 5) cannot install Android APKs, so Ripple will not install there.

What the phone already gives you

Huawei and Honor phones have a Digital Balance section in Settings that shows time per app and can put a limit on an app, with a password. If you are the one who knows the password, you can extend the time when it runs out. If that has not been a problem for you, the built in setting is enough.

If the phone is yours

Ripple for Android (v0.1.28, Android 8.0 or later) lets you give each app a daily amount from 1 minute to 12 hours, cap how many times a day it can be opened, block apps during set hours, or start a one tap focus lock. Since v0.1.27 you can also give all your limited apps one shared daily total, so closing one app and opening another does not buy more time. Making a rule stricter works at once. Loosening a rule takes a wait of 15 minutes by default, or an unlock code. If you would just sit out the wait, give the code to a friend and turn on strict mode, so only the code works. An app set to 0 minutes stays closed all day.

If the phone is your child's

Set the rules on the child's phone and keep the unlock code. A sleep schedule from 9:30 pm to 7 am and a homework schedule on weekday evenings cover the usual fights, and calls and messages still work inside them. With strict mode on, only the code loosens a rule, and Anti-Uninstall turns on with it. Moving the phone clock back does not reset a limit or end a wait early. Ripple has no remote control, so changes are made on the child's phone in person.

Huawei and Honor settings to check

These phones close background apps hard. After turning on accessibility for Ripple, open Settings, Apps, App launch, find Ripple, turn off Manage automatically and allow Autostart, Associated launch and Run in background. Then open Recents and pull the Ripple card down until a lock shows. If the accessibility switch is greyed out, open Ripple's app info, tap the menu in the top right corner and choose Allow restricted settings. Menu names differ a little between versions. Most of my own testing is on an OPPO phone and the Android emulator, so if something acts oddly on a Huawei or Honor phone, the email on the website reaches me.

On iPhone

Ripple for iPhone is v0.1.5 (iOS 16 or later). It blocks chosen apps during set hours, stops apps being deleted, protects against clock changes and uses an unlock code. It has no daily amounts, no shared total, no 0 minute limit, no open count limit and no strict mode.
