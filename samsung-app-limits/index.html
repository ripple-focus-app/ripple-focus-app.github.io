Samsung Galaxy app timers that you keep switching off

I am the developer of Ripple, a free app blocker, so keep that in mind. This page is for people with a Samsung Galaxy phone. Some want to limit their own use. Others are parents setting up a Galaxy phone or tablet for a child.

What Samsung already gives you

Galaxy phones have Digital Wellbeing and parental controls in Settings. You can set an app timer, see screen time per app, and use a focus mode. For a child, Google Family Link adds limits you manage from your own phone. If the built in timer works for you, keep using it.

The common complaint is that the app timer is easy to remove. When the timer runs out you can open Settings, delete the timer and keep going, and it only takes a few seconds. A child who knows the phone well can do the same unless Family Link is set up.

If the phone is yours

Ripple for Android (v0.1.21, Android 8.0 or later) lets you give each app a daily amount, block apps during set hours, cap how many times a day an app can be opened, or start a one tap focus lock. Making a rule stricter applies right away. Loosening any rule takes a 15 minute wait (30 minutes for short video apps), or an unlock code. If you would sit out the 15 minutes, give the unlock code to someone you trust and turn on strict mode, so only the code loosens a rule. A daily amount of 0 minutes keeps an app closed all day.

If the phone is your child's

Set the rules on the child's Galaxy and keep the unlock code yourself. With strict mode on, only the code loosens a rule, at most 3 successful uses a day, and Anti-Uninstall turns on with it on Android 11 or later. Changing the clock does not end a wait early. If you forget the code, a request lifts it after 72 hours.

Ripple has no remote control, so you set everything on the child's phone in person. If you need to change limits from your own phone, Family Link does that and Ripple does not.

One Samsung setting to check

Samsung's battery saving can put apps to sleep in the background. On recent One UI versions you can add Ripple under Settings, Battery, Background usage limits, Never sleeping apps. Ripple also needs the accessibility permission. If that permission is switched off, blocking stops, so check it now and then. On some phones a blocked app can show for a moment before Ripple closes it. Most of my own testing is on an OPPO phone and the Android emulator, so if something behaves oddly on a Galaxy, the email on the website reaches me.

Ripple is not on Google Play or the Galaxy Store. It is installed from the APK on its website.

On iPhone

Ripple for iPhone is v0.1.5 (iOS 16 or later). It blocks chosen apps during set hours, stops apps being deleted, protects against clock changes and uses an unlock code. It has no daily amounts, no 0 minute limit, no strict mode and no open count limit. Apple's Screen Time with a passcode you keep to yourself covers daily amounts.
