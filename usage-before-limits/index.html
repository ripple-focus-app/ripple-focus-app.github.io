Look at a week of usage first, then set the limit

I am the developer of Ripple, a free app blocker with no ads and no account, so keep that in mind. A common way to give up on limits is to pick a number from a guess. Thirty minutes of short videos a day sounds reasonable until you see you were at three hours, and the limit gets switched off by Wednesday. Parents run into the same thing when they set one rule for a child and it ignores the difference between a school day and a Saturday.

Step 1: see how long the app was really used

Since Android v0.1.27, open the limit page of one app and tap the daily usage item, or open usage stats, pick a day, view it by app and tap the app. You see how long that app was used each day over the last 7 days and the last 30 days, with the daily average, the busiest day and the total. Today is left out of the average and the busiest day because it is not over yet. Days with no record are drawn with stripes and do not count toward the average. The page reads the usage records Ripple already keeps, so nothing new is collected.

Step 2: set a limit for each day of the week

Since v0.1.25, the limit page of an app has a per weekday setting. Monday to Sunday can each have their own time. A day can be unlimited, or set to 0 minutes so the app does not open at all that day. Quick settings change Monday to Friday together or Saturday and Sunday together. The block page, the early countdown and today's usage all follow the limit for the current day. Old limits move over unchanged, the same time on every day. The current version is v0.1.29.

Tightening a rule takes effect when you save. If an edit loosens any single day, the whole edit waits, 15 minutes by default or 30 minutes, 1 hour or 2 hours if you pick a longer wait, unless you enter the unlock code. When Ripple released this, the per weekday page and the switch to the new day's limit at midnight had only passed unit tests and had not been checked on a real phone, so look at the limit page the first morning after you set it.

On your own phone

A practical start is to set each day a little under your real average from step 1 and lower it again after a week or two. If you jump between several apps, there is also a daily total shared by all limited apps. It is off by default and starts again at 00:00.

On a child's phone

Ripple has no remote control and no parent app, so you look at the usage page on the child's phone, ideally together with the child. School days can get a short time for games and short videos and the weekend a longer one. Keep the unlock code yourself. With unlock code only mode, which needs an 8 to 12 digit code, waiting no longer loosens anything. On Android 11 and later Anti-Uninstall stops the app from being removed, and changing the clock does not add time.

iPhone

Ripple for iPhone is v0.1.5 and needs iOS 16 or later. It has no usage page and no daily limits. It can block apps during time windows you choose, prevent deleting apps through Screen Time, resist clock changes and use an unlock code. For the first step on an iPhone, Screen Time in the system Settings already shows how long each app was used per day and per week.

What it cannot do

Ripple only works on the phone it is installed on. It does not filter websites. Usage records stay on the phone.
