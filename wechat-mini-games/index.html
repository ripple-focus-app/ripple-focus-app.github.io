Limiting WeChat mini games without blocking WeChat

I am the developer of Ripple, a free app blocker with no ads and no account, so keep that in mind. In China a lot of casual games run as Mini Programs inside WeChat. A child borrows a parent's phone to message a classmate and ends up playing a mini game for an hour. Adults do the same on the bus or in bed. Blocking WeChat entirely is rarely an option, because school groups, work chats and payments all happen there.

What Ripple does here

Since Android v0.1.22, Ripple has a WeChat · Mini Programs item under in-app limits. It is off by default. When you turn it on you choose to block Mini Programs right away or allow a few minutes first. All Mini Programs and mini games share one allowance. When it runs out you go back to the main WeChat screen, and chats, Moments and WeChat Pay keep working. WeChat Channels and Moments have their own items in the same place if you want to limit them too. The current version is v0.1.29.

This item is still new. I have not tested every mini game or Mini Program one by one, so after setting it up, open the few you use most and check that they get blocked.

For a child's phone

Turn on WeChat · Mini Programs with a short allowance or block it outright. Keep the unlock code yourself and turn on strict mode, so only the code can loosen the rule. On Android 11 and later Anti-Uninstall stops the app from being removed, and changing the clock does not add time. If the problem is mostly the evening, a time window can block game apps and other video apps after bedtime as well. There is no remote control, so you set it up on the child's phone.

For yourself

A few minutes a day is often enough to clear a daily reward without losing the evening. Loosening the rule means waiting first, 15 minutes by default, or 30 minutes, 1 hour or 2 hours if you pick a longer wait. You can also give the unlock code to a family member or friend. If you lose it, you can request removal and it unlocks after 72 hours.

iPhone

Ripple for iPhone is v0.1.5 and needs iOS 16 or later. It has no Mini Program limit. It can block whole apps during time windows you choose, prevent deleting apps through Screen Time, resist clock changes and use an unlock code. On iPhone, blocking WeChat in a time window blocks chats too, so pick the hours carefully.

What it cannot do

Ripple only works on the phone it is installed on. It does not filter websites, and a future WeChat update may need changes to the Mini Program detection.
