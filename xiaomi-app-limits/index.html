App limits on a Xiaomi, Redmi or POCO phone that you keep lifting

I am the developer of Ripple, a free app blocker, so keep that in mind. This page is for people with a Xiaomi, Redmi or POCO phone on HyperOS or MIUI. Some want to limit their own use. Others are parents handing one of these phones to a child.

What the phone already gives you

Xiaomi phones have screen time settings where you can see use per app and set a time limit on an app. On global phones this sits under Digital Wellbeing and parental controls, and Google Family Link lets a parent manage a child's phone from their own. If the built in limit works for you, keep using it.

The usual problem is that the person holding the phone can lift the limit. When time is up you can ignore it or remove it in Settings and carry on. A child who knows the phone can do the same unless a parent has locked it down.

If the phone is yours

Ripple for Android (v0.1.22, Android 8.0 or later) lets you give each app a daily amount, block apps during set hours, cap how many times a day an app can be opened, or start a one tap focus lock. Making a rule stricter applies right away. Loosening a rule takes a wait of 15 minutes by default, and you can set it to 30 minutes, 1 hour or 2 hours. An unlock code also loosens rules. If you would sit out the wait, give the code to someone you trust and turn on strict mode, so only the code works. A daily amount of 0 minutes keeps an app closed all day.

If the phone is your child's

Set the rules on the child's phone and keep the unlock code yourself. With strict mode on, only the code loosens a rule, at most 3 successful uses a day, and Anti-Uninstall turns on with it on Android 11 or later. Changing the clock does not end a wait early. If you forget the code, a request lifts it after 72 hours.

Ripple has no remote control, so you set everything on the child's phone in person. If you need to change limits from your own phone, Family Link does that and Ripple does not.

Xiaomi settings to check

Xiaomi phones are strict about apps running in the background. Open Ripple's page in the app settings, allow Autostart, and set its battery saver option to No restrictions. The exact names move around between MIUI and HyperOS versions. Ripple also needs the accessibility permission, and blocking stops if that permission gets switched off, so check it now and then. On some phones a blocked app can show for a moment before Ripple closes it. Most of my own testing is on an OPPO phone and the Android emulator. If something behaves oddly on a Xiaomi phone, the email on the website reaches me.

Ripple is not on Google Play or the Xiaomi app store. It is installed from the APK on its website.

On iPhone

Ripple for iPhone is v0.1.5 (iOS 16 or later). It blocks chosen apps during set hours, stops apps being deleted, protects against clock changes and uses an unlock code. It has no daily amounts, no 0 minute limit, no strict mode and no open count limit. Apple's Screen Time with a passcode you keep to yourself covers daily amounts.
