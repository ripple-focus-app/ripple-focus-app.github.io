App limits on a vivo or iQOO phone that you keep switching off

I am the developer of Ripple, a free app blocker, so keep that in mind. A vivo user once reported a blocking problem to me, which is what got me looking at these phones, and this page collects what I know. It is for people on OriginOS or Funtouch OS who want to limit their own use, and for parents who give one of these phones to a child.

What the phone already gives you

vivo and iQOO phones have screen time settings where you can see how long each app was used and set a limit for it. Global models also have Digital Wellbeing and Google Family Link. If the built in limit works for you, keep using it.

The usual complaint is that the limit is easy to get around. When time is up you can allow more time or turn the limit off in Settings, and a child who knows the phone can often do the same.

If the phone is yours

Ripple for Android (v0.1.22, Android 8.0 or later) lets you give each app a daily amount, block apps during set hours, cap how many times a day an app can be opened, and lock into focus with one tap. Making a rule stricter works right away. Loosening one means a wait of 15 minutes by default, which you can change to 30 minutes, 1 hour or 2 hours, or entering an unlock code. If you know you would sit out any wait, give the code to someone you trust and turn on strict mode so that only the code works. A daily amount of 0 minutes keeps an app closed for the whole day.

If the phone is your child's

Set the rules on the child's phone and keep the unlock code to yourself. In strict mode only the code loosens a rule, at most 3 successful uses a day, and on Android 11 or later Anti-Uninstall turns on as well. Changing the clock does not shorten a wait. If you lose the code, you can request a reset and it is lifted after 72 hours.

Ripple has no remote control, so you set everything on the child's phone in person. If you need to change limits from your own phone, Family Link does that and Ripple does not.

Settings to check on OriginOS and Funtouch OS

vivo phones are strict about apps running in the background. In the settings for Ripple, allow it to start on its own and allow high background power use, and keep it out of battery saving. Menu names change between system versions. Ripple also needs the accessibility permission. If that permission gets switched off, blocking stops, so check it once in a while, especially after a system update.

Ripple is not on Google Play or the vivo app store. You install it from the APK on its website, and the phone will ask you to allow installs from that source.

On iPhone

Ripple for iPhone is v0.1.5 (iOS 16 or later). It blocks chosen apps during set hours, stops apps from being deleted, guards against clock changes and uses an unlock code. It has no daily amounts, no 0 minute limit, no strict mode and no open count limit. For daily amounts on iPhone, Apple's Screen Time with a passcode only you know is the way to go.
